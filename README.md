# NEXORA AI

Projeto de inteligência artificial independente, com experiência mobile-first e identidade visual minimalista em preto, branco e superfícies translúcidas.

## Estado atual

Esta entrega contém a primeira interface navegável:
- layout responsivo para celular e desktop;
- área de conversa e composição de mensagens;
- navegação preparada para Memória, Voz, Criar mídia, Planejamento e Programação;
- seleção local de arquivos e entrada por voz quando o navegador oferece suporte.

## Importante

A interface é um protótipo de frontend. As respostas exibidas são identificadas como demonstração; ainda não existe um modelo de IA conectado. Memória persistente, geração/análise de imagens e vídeos, chamadas, planejamento inteligente e programação assistida dependem da implementação dos serviços de backend, APIs e infraestrutura.

## Executar

Abra `index.html` em um navegador moderno. Para desenvolvimento local, qualquer servidor estático pode servir a pasta.
